ExamBuilder GR patch v0.7.6 RC7

Base version: v0.7.5 RC6

Main changes:
- Central tabs: Exam details, Editing, Images.
- Separate main-question and optional subquestion workspaces.
- Answer-key creation setting moved only to Exam details.
- Horizontal image gallery instead of a long vertical list.
- Standalone or side-by-side image layout.
- Up to four images per row, controlled with row groups.
- Automatic labels: alpha/beta/gamma/delta or Figure 1/Figure 2.
- Same image layout in preview, print, PDF and answer key.

Install:
1. Close the application and Visual Studio.
2. Copy the contents of this patch over the project root.
3. Replace existing files.
4. Delete ExamBuilderGR\bin and ExamBuilderGR\obj if present.
5. Build -> Rebuild Solution.
