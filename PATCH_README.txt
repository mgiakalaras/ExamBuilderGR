ExamBuilder GR v0.7.2 RC3 — Patch πάνω στο v0.7.1 RC2

Περιλαμβάνει:
- πολλές προτάσεις και πολλά κενά στη Συμπλήρωση κενού,
- ανεξάρτητες Στήλες Α/Β με σταθερό τυχαίο ανακάτεμα,
- αντιστοιχίσεις πολλά-προς-πολλά,
- αυτόματο κλειδί λύσεων μετά το ανακάτεμα,
- κεντρική εκφώνηση θέματος,
- υποερωτήματα Α1/Α2/Α3 με ξεχωριστές μονάδες και αυτόματο σύνολο θέματος,
- αυτόματη μετατροπή παλιών αποθηκευμένων δομών.

Εγκατάσταση:
1. Κλείσε εφαρμογή και Visual Studio.
2. Αντέγραψε τα περιεχόμενα του patch επάνω στον φάκελο του project.
3. Επίλεξε Αντικατάσταση όλων.
4. Διέγραψε ExamBuilderGR\bin και ExamBuilderGR\obj.
5. Άνοιξε ExamBuilderGR.sln.
6. Build -> Rebuild Solution.
7. F5.

Δεν χρειάζεται να διαγράψεις παλιά .exam.json, πρότυπα ή ερωτήσεις βιβλιοθήκης.
